# План дипломной работы:

## 1. Проектирование инфраструктуры и сбор данных (Pipeline)
- [+] **Генерация данных:** Создание синтетической популяции с фокусом на колоректальный рак (Synthea R4).
- [+] **Развертывание среды:** Настройка HAPI FHIR (R4) и СУБД ClickHouse.
- [+] **Реализация Bulk Data Pipeline:**
    - Инициирование системного $export из FHIR-сервера.
    - Трансформация NDJSON в реляционные схемы ClickHouse.
    - Оптимизация загрузки (использование движков MergeTree).

## 2. Расширенный исследовательский анализ данных (EDA)
Этот этап закладывает фундамент для построения моделей.
- **Демографический профиль:** 
    - Анализ распределения возраста, пола, расы и семейного положения.
    - Проверка репрезентативности выборки.
- **Анализ клинических групп:**
    - Сегментация пациентов на 3 когорты: «Контроль» (здоровые), «Полипы» (предраковое состояние), «CRC» (рак).
    - Исследование распределения стадий рака внутри группы CRC (по кодам SNOMED).
- **Анализ полноты данных (Data Quality):**
    - Оценка частоты медицинских событий (Observations, Procedures) на одного пациента в каждой группе.
    - Идентификация «пустых» пациентов и работа с пропусками.
    - Поиск временных аномалий (даты смерти раньше дат диагноза и т.д.).
- **Корреляционный анализ:**
    - Поиск первичных связей между лабораторными показателями (Observations) и целевыми группами.

## 3. Оценка риска развития рака у пациентов с полипами
*Цель: Определить вероятность перехода доброкачественного образования в злокачественное.*
- **Формирование выборки:** Выделение когорты пациентов, у которых первичным диагнозом был полип.
- **Инженерия признаков (Feature Engineering):**
    - Время с момента обнаружения первого полипа.
    - Количество процедур (колоноскопий) и динамика анализов крови.
- **Моделирование:** 
    - Обучение бинарного классификатора (например, CatBoost или Random Forest) для предсказания риска конверсии полипа в рак в течение X лет.
- **Метрики:** Оценка Precision-Recall (так как риск пропуска рака критичен).

## 4. Прогнозирование стадии рака (Classification)
*Цель: Определение тяжести заболевания на основе первичных данных до инвазивного вмешательства.*
- **Целевая переменная:** Классификация стадий (например, Ранние I-II vs Поздние III-IV).
- **Набор признаков:** 
    - Лабораторные маркеры (онкомаркеры, показатели воспаления).
    - Коморбидность (сопутствующие диагнозы из таблицы conditions).
    - Социально-демографические факторы.
- **Валидация:** Сравнение точности моделей и интерпретация признаков (Feature Importance) — какие анализы больше всего влияют на стадию.

## 5. Моделирование выживаемости в группах (Survival Analysis)
*Цель: Анализ времени до наступления неблагоприятного исхода.*
- **Кривые Каплана-Мейера:**
    - Сравнение выживаемости пациентов с разными стадиями рака.
    - Сравнение выживаемости в группах «Рак» vs «Полипы» (контроль дожития).
- **Регрессия Кокса (Cox Proportional Hazards):**
    - Оценка влияния факторов (возраст, пол, наличие хирургического вмешательства) на риск смерти.
    - Выявление факторов, максимально снижающих риск (эффективность процедур).

## 6. Интеграция и архитектура решения (опционально)
- **Архитектура обратной связи:** 
    - Проектирование механизма записи результатов предиктов модели обратно в FHIR-сервер в виде ресурсов `RiskAssessment` и `Observation`.
- **Масштабируемость:**
    - Оценка производительности ClickHouse при переходе от тысяч к миллионам записей.
    - Преимущества использования Bulk Data доступа перед стандартным REST API для аналитических задач.
